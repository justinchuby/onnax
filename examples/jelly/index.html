How the computation works · inspect the real ONNX graphs

Browser compatibility: ONNX opset 22. ORT Web 1.31.1's JSEP WebGPU provider is missing the newer Reshape/Unsqueeze registrations needed by these derivative graphs at opset 23/24. This demo is genuinely exported at 22, not relabeled while loading. Other Python examples use opset 24. CPU physics fallback remains disabled.

Python authors spring energy in ONNX IR. onnax.grad(E) produces its gradient; onnax.jvp(grad(E)) produces a Hessian-vector product for a supplied direction. No handwritten runtime derivatives or full Hessian are used.

The implicit objective adds backward-Euler inertia and viscous terms to physical energy (springs, gravity, pointer tether). Safeguarded Newton-CG uses the objective gradient and HVP to find the next position. The force arrows instead use the negative physical gradient: the runtime gradient graph returns this separately in its packed output, without inertia or viscous drag. Pinned coordinates are projected out, so arrows are not support reactions.

ORT WebGPU executes the generated FLOAT32 graphs with CPU execution-provider fallback disabled. Optimized graphs keep buffers and captured commands on GPU; the solver reads back packed positions and physical forces for Canvas 2D rendering. Arrow length is 6 + 30 tanh(|F| / 6) CSS pixels for |F| ≥ 0.02; color uses the same relative magnitude scale. These are illustrative units in a coarse 2D spring model, not calibrated elasticity.

Execution details & limitations

Waiting for a WebGPU adapter.

CPU execution-provider fallback is disabled. Generated H·v graphs and eight CG slots stay on the GPU. Two speculative Newton proposals share one packed readback; the CPU checks every accepted step with an Armijo line search. Rejected speculation is discarded. Small position readbacks feed Canvas 2D rendering. Timings are end-to-end wall time, not GPU-only kernel time. Simulation time does not catch up to wall time on slower devices.

The automated browser smoke test also counts actual WebGPU compute dispatches. Adapter identity and live timings above describe this browser, not a promised framerate.
